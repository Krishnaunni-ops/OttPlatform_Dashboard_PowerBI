# 📺 OTT Data Analysis Dashboard  

This project focuses on analyzing various OTT platform datasets using **Power BI**. The datasets include content from **Netflix, Amazon Prime, and Disney+**, along with ratings from Rotten Tomatoes, Metacritic, and IMDb.  

## 📌 Project Overview  
- **Data Cleaning & Preprocessing:** Utilized **Power BI Query Editor** for data transformation and cleaning.  
- **Visualizations:** Created interactive dashboards using **plots, cards, and charts** to gain insights.  
- **Datasets Used** from Kaggle.

## 📊 Features  
- **Content Analysis:** Genre-wise distribution of movies and shows.  
- **Platform Comparison:** Insights into content availability on **Netflix, Amazon Prime, and Disney+**.  
- **Trends & Popularity:** Year-wise content additions and removals.  
- **Ratings Analysis:** Comparing **IMDb, Rotten Tomatoes, and Metacritic** scores for Netflix titles.  

## 📂 Files  
- `ott_dashboard.pbix` - Power BI dashboard file.  
- `amazon_prime_titles.csv` - Amazon Prime dataset.  
- `disney_plus_titles.csv` - Disney+ dataset.  

## 🚀 How to Use  
1. Open `ott_dashboard.pbix` in **Power BI**.  
2. Explore the different visualizations.  
3. Modify, filter, or add insights as needed.
